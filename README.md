# Restaurantes

Frontend en React + Vite para módulos operativos del sistema.

## Estructura rápida del proyecto

- `src/`
  - `main.tsx`, `App.tsx`, `App.css`
  - `app/`
    - `base/` (componentes/servicios compartidos)
    - `interfaces/` (tipos e interfaces comunes)
    - `modules/` (módulos de negocio)
      - `base/`
      - `cajas/`
      - `clients/`
      - `home/`
      - `impresoras/`
      - `pos/`
      - `reporte/`
      - `restaurante/`
    - `routes/` (ruteo principal)
    - `security/` (autenticación/autorización)
    - `utils/` (helpers)
  - `auth/` (flujo de login y utilidades de auth)
  - `styles/` (estilos globales)
- `public/` (assets estáticos)
- `scripts/` (scripts auxiliares)
- `dist/`, `dev-dist/`, `dist-zip/` (salidas de build/empaquetado)
- `isi_gql_generator.py` (utilidad de generación GraphQL)

## Comandos básicos

- Instalar dependencias: `bun install`
- Levantar en desarrollo: `bun run dev`
- Build producción: `bun run build`
- Vista previa build: `bun run preview`
- Lint/format: `bun run lint`

## Nota sobre `isi_gql_generator.py`

- Es una utilidad para **acortar pasos repetitivos** al generar client, types, queries, mutations y fragments de GraphQL.
- Se ejecuta manualmente con `python3 isi_gql_generator.py` y pide ruta base + endpoint.
- **No es una solución definitiva**: siempre hay que revisar y ajustar el código generado según reglas de negocio, naming, validaciones y casos límite.
- Los archivos generados llevan cabecera `AUTO-GENERATED BY ISI-GQL developer for Nick Russell`.
